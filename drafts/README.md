# drafts/

مسودات النقاش الخام: قوائم الأفكار والقرارات والاعتراضات التي تُلتقط أثناء المحادثات (انظر «تسجيل المسودة» في `prompts/MY-PROMPTS.md`، البرومبت P-001).

**الحالة:** غير معتمدة وغير مراجعة. المسودة ليست مرجعًا، ولا تُقرأ محادثات الأقسام الأخرى منها. ما يُنقل منها بإذن صاحب المشروع يُسجَّل في مكانه الرسمي (سجل الأفكار أو ملفات الطلبات).

## الاسم

ملف لكل جلسة: `YYYY-MM-DD-<القسم>.md`، مثل `2026-10-15-uber.md`.

## القالب

```
# مسودة جلسة <القسم> — YYYY-MM-DD

## القائمة
1. [قلتها أنا] ...
2. [اقتراح من AI] ...
3. [اعترضت عليها] ... (السبب: ...)

## ما نُقل وإلى أين
- (يُملأ بعد الترقية: رقم البند ← الوجهة)

## ما لم يُنقل
- (بنود بقيت في المسودة، ولماذا)
```

## الإجراء

1. أثناء الجلسة تبقى القائمة في المحادثة، وتطلب عرضها من وقت لآخر لتتأكد أنها لم تنقص.
2. في نهايتها تنسخها إلى ملف هنا.
3. تختار أرقامًا لتُنقل، والمحاور ينسقها كفكرة أو طلب.
4. تنسخ أنت المنسّق إلى مكانه الرسمي، وتحدّث قسم «ما نُقل» في المسودة.
