# handoffs/

القناة الوحيدة للطلبات بين الأقسام. إن ظهرت في محادثة قسم فكرة أو حاجة تمس قسمًا آخر، لا تُناقش ولا يُقرَّر فيها؛ تُكتب هنا كطلب.

## البنية

ملف واحد لكل قسم: `to-<القسم>.md` فيه الطلبات الواردة إلى ذلك القسم. محادثة القسم تقرأ ملفها فقط، فلا حاجة لقراءة كل الطلبات.

| الملف | القسم |
|---|---|
| `to-balances.md` | الأرصدة والتسجيل الابتدائي |
| `to-personal-expenses.md` | المصاريف الشخصية |
| `to-uber.md` | الكابتن (أوبر) |
| `to-debts.md` | الديون والالتزامات |
| `to-secondary-repo.md` | المستودع الثانوي |
| `to-reports.md` | التقارير والتحليل |

## صيغة الإدخال

```
- من: <القسم الكاتب> | إلى: <هذا القسم> | الحالة: مفتوح
- المطلوب: <سؤال أو حاجة محددة في سطر أو سطرين>
- الصلة: <الملف أو الفكرة المرتبطة>
```

## الإجراء

1. محادثة القسم الكاتب تعطي صاحب المشروع الإدخال جاهزًا للنسخ.
2. ينسخه صاحب المشروع إلى `to-<القسم المعني>.md` تحت «مفتوحة».
3. عند فتح محادثة القسم المعني تُلصق معها ملفه، فتجد الطلبات وترد عليها.
4. بعد الرد يُنقل الإدخال إلى «مغلقة» مع سطر يذكر القرار أو الرد.

التعريفات المشتركة لا تُطلب من هنا بل تُعدَّل في `rules/GLOSSARY.md` بقرار صاحب المشروع.
