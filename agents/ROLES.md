# ScanX — الأدوار المقترحة للوكلاء

**الحالة:** مسودة مقترحة للنقاش. الأدوار حسب الوظيفة لا حسب الشركة أو النموذج، وإسناد كل دور إلى أداة محددة قرار لاحق لصاحب المشروع.

| الدور | المهمة | ممنوع عليه |
|---|---|---|
| المحاور (عصف ذهني) | يناقش الأفكار ويعارض ويطوّر | الكتابة في السجلات الرسمية |
| أمين السجل | يحوّل ما اتفق عليه صاحب المشروع إلى سجلات وAudit Log بصيغة موحدة | إضافة اقتراحاته أو تغيير حالة فكرة |
| المدقق المستقل | يفحص التعارضات والفراغات والتناقض بين الملفات | الكتابة خارج `reviews/` |
| محقق الحقائق الخارجية | يتحقق من الحقائق الخارجية (مثل حدود يوم أوبر السعودي وقيود iOS) ويعرض المصدر والتاريخ | اعتماد أي قاعدة |
| مدقق الحسابات | يبني أمثلة رقمية مرجعية ويتحقق منها | تعريف المصطلحات |
| المنفّذ والاختبار | مؤجل حتى يقرر صاحب المشروع الانتقال إلى البرمجة | لا يُفعَّل الآن |

**المبدأ:** من كتب شيئًا لا يراجعه.
